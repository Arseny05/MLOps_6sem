Данный посвящен семестровому заданию по практикуму 6 семестра.
Детали задания и баллы см. в ./doc (task и grade соответственно)
Инструкция по развертыванию:
* Перейти на виртуальную машину Codespace, при запуске в web-версии. Либо скачать локально
* Ввести в терминале команду  "docker run -it -v $(pwd):/app data-monitor".
* Программа попросит пользователя ввести параметры сбора данных. По умолчанию вводятся параметры из json-файла gather.json
* Программа автоматически принимает набор данных, эмулирует поток и оценивает их качество
* Пропуски в данных автоматически обрабатываются
* Проводится анализ дрифта данных
* Данные приводятся к единому стандарту для обучения
* После вызывается пользовательский интерфейс ML-системы (для объяснения синтаксиса команд - написать help или ?)
* Для обучения выбранной модели необходимо
  * Добавить датасет командой add_dataset <имя файла> <название таблицы> (команда по умолчанию - "add_dataset database.db var_1")
  * Выбрать датасет для обучения командой set_dataset <dataset_id> (команда по умолчанию - "set_dataset 0")
  * Добавить модель командой add_model <название модели> <id> (команда по умолчанию - "add_model for")
  * Подобрать параметры модели на выбранном датасете командой update_model <id> (команда по умолчанию - 'update_model 1")
* После этого запакованная модель будет сохранена в папку checkpoints, а логи обучения - в models_monitoring.db

Выбор подхода контейнеризацией связан с невозможностью адаптации систем под запуск через bash и возможностью работать сугубо с пользователем через пользовательский интерфейс командной строки.
